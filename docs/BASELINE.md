## Assets and editing boundaries

The following assets are vendor, minified, or dependency bundles and should not be manually edited without deliberately replacing or upgrading the dependency:

- `assets/vendor.js` and `assets/vendor.css`
- `assets/lazysizes.min.js`
- `assets/jquery.cart.min.js`
- `assets/jquery.currencies.min.js`
- `assets/jquery.currencies-format.min.js`
- `assets/fancybox.js`
- `assets/gsap.js`

`config/settings_data.json` and the JSON template files, including `templates/product.json`, declare themselves auto-generated by Shopify's Theme Editor. Treat them as generated configuration: prefer changes through the Theme Editor unless an intentional configuration migration requires a reviewed source edit.

## Third-party app dependency assessment

The active product template has no configured third-party app blocks. Its empty `apps` section does not itself create an app dependency. The main product section supports `@app` blocks, so an app can be added later through the Theme Editor.

`layout/theme.liquid` renders Shopify's `content_for_header`; Shopify or installed apps may inject storefront assets there, which cannot be conclusively enumerated from this repository. The settings data configures `share_product_type: addthis`, indicating an optional AddThis sharing integration, but it is not represented as a populated product-template app block.
