# Components

## Fabric Story

The product template includes a Fabric Story tab sourced from the Shopify product metafield `custom.fabric_story`.

Create this metafield in Shopify Admin under **Settings → Custom data → Products**. Use a rich text field so merchandising teams can manage the story and localized content per product. The tab is hidden when the metafield is empty.

## Craftsmanship

The Craftsmanship tab is sourced from `custom.craftsmanship`. Create it as a rich text product metafield in Shopify Admin. It is hidden until product-specific content is provided.
